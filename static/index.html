Your OpenAI API key

This demo uses your own OpenAI key to generate replies, so usage is billed to your OpenAI account (a full demo conversation typically costs a few US cents with the default model).

The key is sent to this demo's server over HTTPS and kept only in memory for your chat session. It is used only to call OpenAI, is never logged or saved, and is dropped when the session ends or expires. Reloading the page forgets it. If you'd rather not share a key with a hosted demo, run it locally with the key in .env (see the README).
